## 与首版引擎的关系

这套商业实景本不是可以直接发布的 JSON：它有多幕演绎、NPC 串场、分支阅读和情感收束，现有首版引擎只保证“搜证＋投票＋揭晓”的推理短本。当前应把《乱春》导入为待审核材料，先核对角色知情范围、每一幕的解锁关系、线索可见范围和最终结局，再判断是否需要扩展阶段类型；不能把 OCR 猜测或手册中的 DM 话术自动当成角色事实。网页剧本馆支持一次选择多个文件或整个资料文件夹；海报、音频会跳过，纯扫描 PDF 会在资料包中逐页 OCR，不会被当作空剧本强行解析。

## OCR 命令

在 macOS 上可运行：

```sh
scripts/ocr-pdf.sh "/Users/caotc/Downloads/2194-乱春/乱春剧本/不   悔A.pdf" /tmp/buhui.ocr.md
```

OCR 结果只用于解析和人工核对。上传发布仍要求原文引用，缺少引用、引用无法在原文找到或角色权限不明确时，服务端会阻止发布。

如果要把整套资料一次性整理成一个待审核材料包，可以对目录运行：

```sh
scripts/ocr-directory.sh "/Users/caotc/Downloads/2194-乱春/乱春剧本" /tmp/luanchun.ocr-bundle.md
```

目录级命令会逐个 PDF 保留文件名和页码标记。生产资料包实测超过单次解析上限。应一次选择整套目录，将手册、角色本和线索本保存在同一资料包，随后逐页核对；不要把单份角色本解析成独立剧本，也不要把合并 OCR 文件直接发布为可玩剧本。
