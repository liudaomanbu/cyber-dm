## 已核对到的结构

- 玩家角色为六人：林路平、春游、纪舜英、纪舜华（手册部分页面写作“纪蕣华”）、沈梦秋、颜无依。手册还安排如一、李不言、颜心等 NPC／DM 演绎角色。
- 手册流程包含序幕、第一幕至第五幕，以及后续“诀别谭”沉浸流程；完整体验约 6.5–7 小时。
- 主要世界观资料包括金兰盟、绝影殿、天魔波旬、明武堂和除恶阵。
- `四幕线索.pdf` 的线索涉及除恶阵规则、长老玉牌、绝影殿、钱十七、天魔波旬及解除方法、以身饲魔之术。
- 《乱春手册.pdf》有文字层，可直接作为解析模型的原文输入。
- 角色本和线索本大多是扫描图片 PDF；已用 macOS Vision 生成 OCR 草稿，输出在本机 `.data/luanchun-ocr/`，其中每页保留了页图标识，便于逐页复核。

## 与首版引擎的关系

这套商业实景本不是可以直接发布的 JSON：它有多幕演绎、NPC 串场、分支阅读和情感收束，现有首版引擎只保证“搜证＋投票＋揭晓”的推理短本。当前应把《乱春》导入为待审核材料，先核对角色知情范围、每一幕的解锁关系、线索可见范围和最终结局，再判断是否需要扩展阶段类型；不能把 OCR 猜测或手册中的 DM 话术自动当成角色事实。

## OCR 命令

在 macOS 上可运行：

```sh
scripts/ocr-pdf.sh "/Users/caotc/Downloads/2194-乱春/乱春剧本/不   悔A.pdf" /tmp/buhui.ocr.md
```

OCR 结果只用于解析和人工核对。上传发布仍要求原文引用，缺少引用、引用无法在原文找到或角色权限不明确时，服务端会阻止发布。

如果要把整套资料一次性整理成一个待审核材料包，可以对目录运行：

```sh
scripts/ocr-directory.sh "/Users/caotc/Downloads/2194-乱春/乱春剧本" /tmp/luanchun.ocr-bundle.md
```

目录级命令会逐个 PDF 保留文件名和页码标记。完整资料可能超过首版解析模型的单次输入上限，实际导入时建议先上传《乱春手册.pdf》，再按幕或按角色分批 OCR、审核；不要把合并 OCR 文件直接发布为可玩剧本。
