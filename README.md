# Cyber DM

面向 PC 和手机浏览器的 AI 语音剧本杀。Web 版优先，原生客户端为后续优化项。

## 开发状态

已实现原创短本、任选角色、阶段／搜证／投票引擎、角色上下文过滤、严格台词选择、会话文件持久化、响应式页面及服务配置界面。支持 Chat Completions、Responses、Anthropic Messages 三种模型协议适配。

**目前不是满足最终验收的版本。** 已实现浏览器麦克风 PCM 采集、灵矽 WebSocket 桥接、下行 Opus 解码、第三方 SSE 回调及 PDF／文本解析草稿流程，但仅通过本地协议测试，尚未连接真实灵矽服务或完成手机语音实测。音色自动匹配、声音克隆、公开部署访问认证仍待完成。

上传支持结构化 JSON，以及 PDF／UTF-8 TXT／Markdown。非 JSON 文件使用配置的解析模型形成草稿，必须核对原文、角色知情范围、阶段和结局后发布；缺少原文引用会阻止发布。扫描 PDF 暂不支持 OCR。首次版本仅支持有投票和揭晓结局的完整推理本。

## 运行

需要 Node.js 22 或更新版本。

```sh
npm ci
npm run build
npm start
```

打开 http://127.0.0.1:3001 。开发时使用 `npm run dev`，Vite 页面代理至 3001 端口。

在“连接与声音”填写 provider（基地址应包含服务要求的 `/v1` 等前缀）、协议、模型 ID 和 API Key，然后为每个角色和 DM 分配服务。未配置不会伪装成 AI 响应。

当前服务器仅监听本机。配置与会话保存在 `.data/`，不纳入 Git；密钥在本地文件保存并限制文件权限，尚未实现磁盘加密。当前配置页拥有本机全部配置权限，**不要直接公开部署**；远程访问认证、HTTPS 和房间隔离需要进一步实现。

## 验证

```sh
npm test
npm run build
```

测试覆盖角色秘密／私聊隔离、玩家证词不写入事实、非法线索与台词拦截、状态版本检查，以及每个可选角色到终局的路径。另有原文引用校验、文本提取和模拟灵矽服务测试，覆盖回调鉴权、会话绑定、去重和音色参数。它们不替代真实服务和移动设备测试。

`examples/after-hours.json` 是原创短本《闭馆之后》，包含完整事实与结局，玩家请勿提前阅读以免剧透。它也是当前结构化导入格式的示例。此首版引擎当前只支持以投票和揭晓结尾的推理本，其他机制尚未实现。

详细目标、预算、时间、技术边界与验收条件见 [需求与架构](docs/requirements-and-architecture.md)。

## 灵矽联调准备

在“连接与声音”填写灵矽 API Key、WebSocket Token、Device ID、Client ID、Agent ID 与业务回调 Token，并为 DM 和所有 AI 角色设置 TTS provider / voice_type。平台的第三方业务服务应指向：

```text
https://你的域名/integrations/linx/chat/stream
Authorization: Bearer 与界面配置相同的回调Token
```

此地址必须可由灵矽访问；浏览器到本服务需 HTTPS/WSS 才能在手机上使用麦克风。暂勿在缺少访问认证时公开完整服务，后续将提供受保护部署方案。设备绑定及第三方模式开通以账号实际权限为准。

进入房间后点击“连接麦克风”，再点击开始／结束录音。可说“下一阶段”“搜查＋线索名称”“确认投票＋角色全名”，其他语音作为公开讨论。当前语音私聊、自然语言意图泛化、音色试听、自动分配和播放完成回执仍待完善。切到后台会关闭麦克风和连接，返回后重新连接，游戏状态保留。

语音协议假定上行 PCM、下行按 hello 协商 PCM 或 Opus。模型输出经过规则校验后返回 SSE；没有游戏回复的轮次不放行平台音频。平台对旧音频的取消顺序、多消息变声与音频完成反馈仍须真实联调验证。
