# Cyber DM

面向 PC 和手机浏览器的 AI 语音剧本杀。Web 版优先，原生客户端为后续优化项。

## 开发状态

已实现原创短本、任选角色、阶段／搜证／投票引擎、角色上下文过滤、严格台词选择、会话文件持久化、响应式页面及服务配置界面。支持 Chat Completions、Responses、Anthropic Messages 三种模型协议适配。

**目前不是满足最终验收的版本。** 已实现浏览器麦克风 PCM 采集、灵矽 WebSocket 桥接、下行 Opus 解码、第三方 SSE 回调及 PDF／文本解析草稿流程，但尚未连接真实设备完成手机语音实测。已加入音色目录读取、默认分配、原生灵矽音色 ID 播放、参考音频上传与复刻训练界面，以及可选访问口令认证；平台目录和原生 WebSocket 音色切换已用公开 API 响应及模拟链路验证，真实设备仍需账号侧绑定。

上传支持结构化 JSON，以及 PDF／UTF-8 TXT／Markdown。非 JSON 文件使用配置的解析模型形成草稿，必须核对原文、角色知情范围、阶段、线索、台词和结局后发布；角色资料、阶段、事实、线索、台词和结局均需有可在原文中定位的引用，缺少或伪造引用会阻止发布。扫描 PDF 可先在 macOS 上运行 `scripts/ocr-pdf.sh` 生成带页码的 OCR 草稿，再把 OCR 文本交给解析模型；OCR 结果只作为待审核材料，不能绕过引用校验。首次版本仅支持有投票和揭晓结局的完整推理本。

## 运行

需要 Node.js 22 或更新版本。

```sh
npm ci
npm run build
npm start
```

打开 http://127.0.0.1:3001 。开发时使用 `npm run dev`，Vite 页面代理至 3001 端口。

手机浏览器要使用麦克风，部署时必须通过 HTTPS/WSS。除反向代理外，也可以直接给服务端提供证书：`HOST=0.0.0.0 CYBER_DM_TLS_CERT=/path/fullchain.pem CYBER_DM_TLS_KEY=/path/privkey.pem npm start`；浏览器访问对应的 `https://` 地址即可。证书路径只从环境变量读取，不写入配置页面或仓库。

在“连接与声音”填写 provider（基地址应包含服务要求的 `/v1` 等前缀）、协议、模型 ID 和 API Key，然后为每个角色和 DM 分配服务。未配置不会伪装成 AI 响应。

设置页的“发车检查”会逐项显示剧本、解析模型、角色模型、角色音色和灵矽桥是否齐全；它只返回配置状态，不会显示或记录密钥。只有检查全部通过后，才建议进行语音整局验收。

剧本馆支持输入创作要求生成原创剧本草稿，也支持对已有剧本提出自然语言改编要求。两种结果都会进入人工核对区，核对角色知情范围、线索、台词和结局后才可发布；改编不会修改正在进行的房间，AI 生成内容不会被当作事实依据。

当前服务器仅监听本机。配置与会话保存在 `.data/`，不纳入 Git；密钥在本地文件保存并限制文件权限，尚未实现磁盘加密。当前配置页拥有本实例全部配置权限。远程验收需要设置至少 16 字符的 `CYBER_DM_ACCESS_CODE` 和准确的 `CYBER_DM_PUBLIC_ORIGIN`（例如 `https://game.example.com`），再通过 HTTPS 反向代理访问。此口令是单用户实例访问保护，不是多人账号与房间授权系统。

## 验证

```sh
npm test
npm run build
```

测试覆盖角色秘密／私聊隔离、玩家证词不写入事实、非法线索与台词拦截、状态版本检查，以及每个可选角色到终局的路径。另有原文引用校验、文本提取与原创草稿、模型协议、访问保护、就绪检查和模拟灵矽服务测试，覆盖回调鉴权、会话绑定、去重、旧轮次失效、音色参数和默认分配。当前全量测试为 23 项通过；它们不替代真实服务和移动设备测试。

`examples/after-hours.json` 是原创短本《闭馆之后》，包含完整事实与结局，玩家请勿提前阅读以免剧透。它也是当前结构化导入格式的示例。此首版引擎当前只支持以投票和揭晓结尾的推理本，其他机制尚未实现。

详细目标、预算、时间、技术边界与验收条件见 [需求与架构](docs/requirements-and-architecture.md)。

有域名时的 HTTPS 子域名、Caddy 反代、灵矽回调和真机验收步骤见 [HTTPS 部署](docs/deployment.md)。

## 灵矽联调准备

在“连接与声音”填写灵矽 API Key、WebSocket Token、Device ID、Client ID、Agent ID 与业务回调 Token，并为 DM 和所有 AI 角色绑定灵矽音色 ID。平台的第三方业务服务应指向：

```text
https://你的域名/integrations/linx/chat/stream
Authorization: Bearer 与界面配置相同的回调Token
```

此地址必须可由灵矽访问；浏览器到本服务需 HTTPS/WSS 才能在手机上使用麦克风。远程访问必须启用上文的访问口令，并由 HTTPS 反向代理保护；不要直接暴露无认证实例。设备绑定及第三方模式开通以账号实际权限为准。

进入房间后点击“连接麦克风”，再点击开始／结束录音。可说“下一阶段”“搜查＋线索名称”“投票＋角色全名”；关键操作会先复述，必须再说“确认执行”才生效，也可说“取消操作”。其他语音作为公开讨论，选择对象后支持私聊。自然语言意图泛化和播放完成回执仍待完善。切到后台会关闭麦克风和连接，返回后重新连接，游戏状态保留。

语音协议假定上行 PCM、下行按 hello 协商 PCM 或 Opus。模型输出经过规则校验后返回 SSE；没有游戏回复的轮次不放行平台音频。平台对旧音频的取消顺序、多消息变声与音频完成反馈仍须真实联调验证。
